☕ Cafeteria Website

Um site moderno de cafeteria desenvolvido com HTML5 e CSS3, focado em design elegante, responsividade e boa experiência do usuário.

---

📌 Sobre o Projeto

Este projeto foi criado para praticar e demonstrar habilidades em desenvolvimento front-end, construindo uma interface visual atrativa para uma cafeteria.

O site apresenta uma navegação simples, com seções bem organizadas e um estilo moderno.

---

🚀 Tecnologias Utilizadas

- HTML5
- CSS3

🎯 Funcionalidades

- Interface intuitiva
- Estilização personalizada
